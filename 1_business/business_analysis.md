# Business Analysis｜商业模式分析

> 角色：**Investment Source**。用于训练“看懂一门生意”的稳定分析框架；不直接输出买卖结论。

## 一句话

> **商业分析的核心不是描述公司，而是解释：价值如何创造、利润如何形成、优势为何持续、增长为何可能。**

## 1. 七个核心问题

面对任何公司，先回答：

```text
1. 客户是谁？
2. 客户为什么付钱？
3. 公司靠什么赚钱？
4. 主要成本与约束是什么？
5. 利润为什么留在这里？
6. 竞争者为什么抢不走？
7. 再增长 10 倍，哪个变量最先成为瓶颈？
```

回答不清楚时，默认：**尚未真正理解商业模式。**

## 2. 价值创造链

```text
Customer Pain / Need
→ Product / Service
→ Willingness to Pay
→ Revenue Model
→ Unit Economics
→ Cash Flow
```

重点不是“产品很好”，而是：

```text
价值有没有被创造？
价值有没有被公司捕获？
捕获之后有没有转成现金？
```

## 3. 收入机制

拆清：

```text
客户数
× 使用频次
× 客单价
× 付费率
× 留存 / 续费
```

不同商业模式选择真正有效的驱动变量，不机械套公式。

## 4. 成本与资本效率

至少识别：

```text
固定成本
变动成本
获客成本
履约成本
研发 / 销售投入
营运资本
资本开支
```

然后追问：

> **增长 1 元收入，需要额外投入多少资本？**

高增长但持续吞噬资本，不等于高质量增长。

## 5. 竞争优势

不要停在“品牌 / 技术 / 规模”名词，必须写机制：

```text
优势变量
→ 如何降低成本 / 提高支付意愿 / 提升留存 / 抑制竞争
→ 为什么竞争者难复制
→ 优势持续所需条件
→ 哪个信号意味着优势开始衰减
```

常见候选：

```text
规模经济
网络效应
转换成本
品牌 / 信任
渠道 / 分发
数据 / 学习曲线
牌照 / 稀缺资源
流程 / 组织能力
```

这些只是候选，不是看到名词就算护城河。

## 6. 增长机制

增长必须追溯来源：

```text
市场自然增长
份额提升
提价
新品 / 新区域
并购
资本投入
```

再判断：

```text
增长是否可复制？
边际回报是否下降？
增长是否破坏原有优势？
```

## 7. 管理层与资本配置

管理层评价不只看“愿景”，而看：

```text
资源投向哪里？
ROI 如何？
自由现金流怎么分配？
回购 / 分红 / 并购 / 再投资是否创造价值？
承诺与结果是否一致？
```

## 8. 输出格式

一家公司分析最终压缩为：

```text
商业模式：
客户价值：
赚钱机制：
核心变量：≤3
竞争优势：
增长机制：
资本效率：
最大脆弱点：
什么事实会证明我没看懂：
```

一句话：

> **先解释钱为什么会持续留下来，再谈公司是不是“好公司”。**
