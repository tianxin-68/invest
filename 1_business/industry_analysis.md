# Industry Analysis｜行业结构分析

> 角色：**Investment Source**。用于判断行业利润池、竞争结构与长期变化，不直接把宏观/行业观点映射成买卖动作。

## 一句话

> **行业分析的核心不是判断“行业好不好”，而是解释：利润为什么在这里、会向哪里迁移、什么力量会重写结构。**

## 1. 固定分析链

```text
Demand
→ Supply
→ Value Chain
→ Profit Pool
→ Competition
→ Moat / Entry Barrier
→ Technology / Regulation / Cycle
→ Structural Change
```

## 2. 需求

回答：

```text
谁在买？
为什么买？
需求是刚需、可选还是替代性需求？
量增长来自人口、渗透率、频次还是升级？
价格弹性如何？
什么情况下需求会消失或迁移？
```

不要把 TAM 大直接等同于行业价值大。

## 3. 供给

识别：

```text
参与者数量
产能扩张速度
供给弹性
退出成本
库存 / 产能周期
同质化程度
```

关键问题：

> **需求增长带来的利润，会不会迅速被新增供给吃掉？**

## 4. 产业链与利润池

先画：

```text
上游 → 中游 → 下游 → 渠道 → 客户
```

对每一环问：

```text
收入规模？
毛利 / 现金流质量？
议价权？
资本强度？
集中度？
替代风险？
```

然后定位：

> **整个产业链中，利润为什么集中在某些环节？**

## 5. 竞争结构

至少判断：

```text
市场集中度
竞争维度（价格 / 产品 / 渠道 / 品牌 / 服务 / 规模）
新进入者成本
客户转换成本
供应商议价权
客户议价权
替代品
```

目标不是套“五力模型”名词，而是找到真正改变利润率的变量。

## 6. 行业阶段

区分：

```text
导入期
高速渗透期
集中度提升期
成熟期
衰退 / 重构期
```

同一家公司在不同阶段，增长质量和竞争优势可能完全不同。

## 7. 结构变化

重点跟踪：

```text
技术：成本曲线 / 产品能力 / 替代路径
监管：准入 / 价格 / 合规 / 补贴
资本：融资成本 / 产能扩张 / 并购
渠道：流量 / 分发 / 客户触达
客户：偏好 / 预算 / 使用习惯
```

变化必须走机制链：

```text
External Change
→ Industry Variable
→ Profit Pool / Competition
→ Company Economics
```

禁止直接：

```text
降息 / 政策利好 / AI 热潮
→ 行业一定上涨
```

## 8. 输出格式

```text
行业一句话：
核心需求变量：≤3
核心供给变量：≤3
产业链：
利润池：
竞争结构：
当前阶段：
最重要结构变化：
谁受益 / 谁受损，为什么：
最大反证条件：
```

一句话：

> **先找到利润池和重分配机制，再讨论行业机会。**
