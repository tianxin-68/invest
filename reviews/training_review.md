# Investor Formation Review｜投资能力训练复盘

> 用于复盘“心性—商业—行业—估值—校准”的训练质量，不以短期市场结果评价能力。

## 1. 本周期训练对象

```text
心性机制：
公司：
行业：
完整 Thesis：
```

## 2. 判断质量

逐项回答：

```text
关键变量有没有找对？
变量之间的机制有没有讲通？
事实与解释有没有分开？
有没有主动寻找最强反例？
反证条件是否具体？
哪些地方输出了 unknown？
```

## 3. 商业判断

```text
客户价值是否讲清？
赚钱机制是否讲清？
利润为什么留在这里？
竞争优势是否写了机制而非名词？
增长需要多少资本？
最先失效的变量是什么？
```

## 4. 行业判断

```text
需求 / 供给是否分开？
产业链是否画清？
利润池在哪里？为什么？
竞争结构最关键变量是什么？
技术 / 监管 / 周期变化通过什么机制传导？
```

## 5. 估值判断

```text
是否区分 Good Company 与 Investment Attractiveness？
是否识别市场隐含预期？
是否使用情景而非单点精确值？
最大敏感变量是什么？
```

## 6. 心性与偏差

```text
我最想证明哪个观点？
是否因为投入时间而不愿放弃？
是否借用了权威 / 群体的确定性？
是否把结果当成能力证明？
是否允许 unknown？
```

## 7. Reality Calibration

对 3~6 个月前的判断回看：

```text
当时看对了什么？
看错了什么？
漏掉了什么？
是变量错、机制错、概率错，还是后来出现新信息？
哪个 Source 需要 Correction Candidate？
```
