# Valuation Judgment｜估值判断

> 角色：**Investment Source**。用于训练“商业价值与价格”的分离判断；当前阶段强调反推预期与情景，而非追求精确目标价。

## 一句话

> **估值不是给公司贴一个价格，而是判断：当前价格要求哪些未来事实成立。**

## 1. 先分开两个问题

```text
Company Quality
!=
Investment Attractiveness
```

好公司如果价格包含过高预期，仍可能不是好投资；普通公司如果预期极低，也可能存在赔率。

## 2. 估值的核心对象

不是 PE / PS 本身，而是：

```text
Future Cash Flow
× Growth Duration
× Return on Incremental Capital
× Risk / Uncertainty
× Price
```

估值倍数只是这些变量的压缩表达。

## 3. 反推市场预期

看到价格时先问：

```text
市场隐含了多高增长？
增长要持续多久？
利润率要达到多少？
需要怎样的资本效率？
竞争优势要持续多久？
哪些风险被价格忽略？
```

目标是从：

```text
“这只股票贵不贵？”
```

升级到：

```text
“这个价格隐含的未来，我认同多少？”
```

## 4. 情景而非单点

至少写：

```text
Bear
Base
Bull
```

每个情景明确：

```text
关键变量
机制
概率 / 不确定性
价值区间
```

禁止为了得到一个目标价而给所有变量伪精确数字。

## 5. 安全边际

安全边际不是固定折价百分比，而来自：

```text
认知不确定性
业务波动
财务脆弱性
竞争变化
估值敏感度
```

不确定性越高，越不能依赖单一精确估值。

## 6. 最小估值判断

当前训练阶段，每家公司至少能回答：

```text
1. 价值主要由哪 3 个变量决定？
2. 当前价格最依赖哪个乐观假设？
3. 哪个变量一旦低于预期，估值会明显坍塌？
4. 我与市场的主要分歧是什么？
5. 哪个事实会证明市场比我更对？
```

## 7. 输出格式

```text
当前价格 / 估值参考：
核心价值变量：≤3
市场隐含预期：
Bear：
Base：
Bull：
最大估值敏感项：
主要分歧：
反证条件：
当前判断：cheap | fair | expensive | unknown
置信度：low | medium | high
```

`unknown` 是正式结果；看不懂不等于必须给估值。

一句话：

> **先判断价格里装了什么预期，再判断这个预期值不值得相信。**
