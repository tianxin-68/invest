# Investor Temperament｜投资者心性

> 角色：Investment Source。训练在不确定、延迟反馈和观点冲突中的判断稳定性；通用人性机制仍由 `tx` 定义。

## 核心目标

```text
允许不知道
允许犯错
允许错过
观点与身份分离
过程与结果分离
事实与解释分离
主动寻找反例
持续保留可证伪条件
```

## Slow Path

```text
1. 当前问题是什么？
2. 已知事实是什么？
3. 最重要变量 ≤3 是什么？
4. 变量通过什么机制影响结果？
5. 哪个假设最可能错？
6. 什么事实会改变判断？
7. 信息不足时，明确输出 unknown。
```

## 反自证

对最相信的判断，至少补齐：

```text
最强反例
竞争解释
Failure Condition
```

如果只能找到支持材料，没有反证路径，Thesis 仍不成熟。

## Reality Calibration

复盘时区分：

```text
Process Correct / Result Good
Process Correct / Result Bad
Process Wrong / Result Good
Process Wrong / Result Bad
```

短期结果不能替代对当时判断过程的评价。

## 当前训练

```text
公司 / 行业研究
→ 冻结 Facts / Thesis / Key Variables
→ 写 Failure Conditions
→ 3~6 个月后回看 Reality
→ 找变量错 / 机制错 / 概率错 / 新信息
```

一句话：

> **投资心性不是更自信，而是更能在现实面前修正自己。**
