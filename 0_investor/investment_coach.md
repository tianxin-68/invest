# Investment Coach｜投资教练

> **职责**：把高质量外部投资文章编译成可训练的投资判断输入，并形成可追溯的长期训练记录。
>
> 它不是新的 Investment Source，也不是荐股系统。

## 1. Objective

```text
High-quality External Evidence
→ Key Judgment Extraction
→ Investor Drill
→ Owner Reflection
→ Later Reality Review
→ Source Correction Candidate
```

目标不是增加阅读量，而是持续训练：

```text
Business Judgment
Industry Judgment
Valuation / Expected Return
Capital Allocation
Risk Discipline
Investor Temperament
```

## 2. Cadence

```text
每周 2 次
→ 每次 1 篇
→ 周二 / 周五 19:00（Asia/Tokyo）
```

每次只选择一篇真正值得读的内容；允许经典文章，不为了“最新”牺牲质量。

## 3. Selection Gate

优先选择会改变或训练以下判断的文章：

```text
商业模式 / 竞争优势
行业结构 / 利润池
估值 / 隐含预期
资本配置
风险管理
投资心性 / 决策纪律
```

默认排除：

```text
短线热点
价格预测
无机制支撑的观点
机械资讯汇总
为了凑数的推荐
```

## 4. Output Contract

每篇固定输出：

1. 标题、作者 / 来源、原文链接；
2. 为什么现在值得读；
3. 3 个关键判断；
4. 本篇训练的投资能力；
5. 1 个可立即练习的投资思考题；
6. Classification：`Evidence / Candidate`。

同一份内容同时：

```text
ChatGPT Push
+ Gmail → me
+ Append → 0_investor/investment_coach.md
```

Gmail 主题：

```text
投资教练｜YYYY-MM-DD｜<文章短标题>
```

## 5. Definition Authority

外部文章无论作者多权威，都只默认属于：

```text
Investment Evidence / Candidate
```

不得因为观点漂亮或一次验证成功直接升级为稳定规则。

升级路径：

```text
Repeated Use
+ Counterexample Check
+ Owner Judgment
+ Reality Review
→ Source Correction Candidate
→ Owner Gate
→ Corresponding Investment Source
```

## 6. Stop Rule

如果本篇内容不能明显训练或改变：

```text
Thesis
Probability
Valuation
Risk
Behavior Discipline
Capital Allocation Judgment
```

则不推荐。

> **宁缺毋滥：每周两篇是上限目标，不是凑数 KPI。**

## 2026-08-25｜The Calculus of Value

**作者 / 来源**：Howard Marks / Oaktree Capital  
**发布日期**：2025-08-14  
**原文**：https://www.oaktreecapital.com/insights/memo/the-calculus-of-value  
**Classification**：`Evidence / Candidate`

### 为什么现在值得读

这篇文章最值得训练的不是“怎么算估值”，而是把三个经常被混在一起的对象拆开：

```text
Business Quality / Earning Power
→ Value
→ Price
```

好公司并不自动等于好投资。投资回报取决于：对未来 earning power 的判断是否正确，以及为这种 earning power 支付了什么价格。

### 3 个关键判断

1. **价值的底层是 earning power，不是故事。** 厂房、品牌、专利、管理层、文化、技术能力之所以有投资价值，是因为它们能够转化为当前或未来的盈利能力与现金流。公司分析必须继续追问：这个优势最终如何进入利润与自由现金流？
2. **Price 和 Value 是两个独立变量。** `Good Company != Good Investment`。公司再优秀，如果价格已透支未来，预期收益仍可能很差；普通公司在极低价格下也可能产生不错的风险调整后收益。
3. **短期收益大量来自心理变化，长期收益才更多回归基本面。** 可把收益来源拆成 `Return = Change in Value + Change in Price / Value Relationship`。判断最终会回归价值并不够，仓位、流动性和时间期限必须允许你活到价值兑现。

### 本篇训练能力

`Valuation / Expected Return Judgment`

固定训练顺序：

```text
Business Reality
→ Earning Power
→ Intrinsic Value
→ Current Price
→ Implied Expectations
→ Expected Return
```

避免从“我看好这个公司”直接跳到“可以买”。

### Investor Drill

选一家你直觉上认为“很优秀”的公司，只回答：

> 当前股价已经隐含了未来 3–5 年怎样的收入增长、利润率和竞争优势？如果公司只是“表现很好”，但没有超过这些隐含预期，我还能赚到什么钱？

先拆开“公司质量”和“价格隐含预期”，不要先判断涨跌。

### Source Gate

本篇仅作为 `Evidence / Candidate`。只有经过重复应用、反例检查、Owner 判断与后续 Reality Review，才可能形成 `Source Correction Candidate`；不因 Howard Marks 的权威性直接升级为稳定 Investment Source。
